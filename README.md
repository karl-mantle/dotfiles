# dotfiles

dotfiles, configs and scripts

```bash
git clone https://github.com/karl-mantle/dotfiles.git
cd dotfiles
``

## Ubuntu

Written for Ubuntu 26.04 LTS

### Setup

Setup script for installing and configuring:

- SSH
- Git
- NVM/Node.js

```bash
cd dotfiles/setup/
chmod +x /setup.sh
./setup.sh
``
